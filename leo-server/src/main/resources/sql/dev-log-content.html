缘起：从一张截图开始

这个站点的起点是一次「复刻练习」：把 zyyo.net 的界面结构与视觉风格搬下来，再逐步改造成自己的样子。从第一版 Vue 3 + Vite 脚手架，到今天前后端完整跑通的 Leo 个人站，前后经历了十个阶段。这篇 Blog 把整个开发路程完整记录下来。

技术栈与工程结构

  • 前端：Vue 3 + Vite，组件按 views / components / composables / api 分层；axios 统一封装，预留与 Spring Boot 对接的接口层。
  • 后端：Spring Boot 3.2.5 + MyBatis-Plus + MySQL（库 leo_blog，共 8 张表），统一返回体 { code, message, data }。
  • 开发联调：Vite 代理 /api 与 /uploads 到 8080；前端 .env.development 中 VITE_USE_MOCK=false 即走真实接口。
  • 主题：CSS 变量驱动的浅色 / 深色双主题，顶栏一键切换并持久化。

第一阶段：站点骨架

先搭建了与参考站一致的页面框架：顶部导航（Logo 悬停扫描线 + 菜单 + 音乐抽屉开关 + 主题开关 + 账户）、Home 的 3×3 网格布局（Hero 自我介绍 / Now Playing 音乐 / Now 时钟 / Console 终端 / Theme 主题 / 相册 / SiteInfo 站点信息）、页脚、加载动画。Hero 右侧还放入了本地 GLB 模型，支持鼠标左右拖动旋转。

第二阶段：品牌迁移 Zyyo → Leo

把页面里所有 Zyyo 字段替换为 Leo，包括加载动画遗留的 Zppo 拼写问题（加载动画文案来自站点配置而非页面文案，逐一排查后修复）。

第三阶段：后端与数据库

按参考图建好 leo_blog 数据库：文章表、标签表、随记表、站点配置表、跑马灯标签表；随后补齐相册照片表、照片评论表、音乐曲目表。后端提供文章 / 随记 / 站点 / 相册 / 音乐五组查询接口，登录走内存 Token（30 分钟过期），管理员账户存于站点配置。

第四阶段：Home 编辑模式

顶栏账户按钮输入管理员账号密码进入编辑模式：页面文字原地可编辑（contenteditable），有修改时右下角浮动保存条，整体 PUT /api/home 保存。固定文案（Toggle theme、Broken thoughts、Now Playing 等）不参与编辑。

第五阶段：Blog

列表页展示标题、日期、摘要卡片；详情页左侧正文 + 右侧「On this page」目录列（完全还原参考站）。编辑模式直接在页面内编辑正文，选中文字弹出 Word 同款样式栏（加粗、字号、文字颜色等）；新建文章跳转空模板页，保存后生成年月日时分编号的 slug 路由。

第六阶段：Notes

随记页按时间倒序展示，当前页直接编辑时间与内容，可新建、删除；Notes 与 Blog 页都加了 300ms 防抖搜索框，对标题与正文做模糊查询。

第七阶段：About

关于页 87 个可编辑字段全部接入编辑模式：按 data-path 定位字段、原地编辑、整体保存；tags 数组 / status 中英文 / 数字类型在保存时自动还原，避免类型错乱。

第八阶段：Photos

参照 QQ 相册做了相册化三级结构：相册列表（封面 + 张数）→ 相册详情（年月筛选 + 编辑模式上传 / 删除 / 原地改信息）→ 大图弹窗（左右翻页、键盘操作、下载到本地、编辑模式弹窗内上传、右侧作者描述 + 访客评论栏）。删除照片会连带清理评论，避免孤儿数据。

第九阶段：Music

布局参考深蓝互动官网 MUSIC 板块，做了 Leo 风格的曲目墙：顶部 3 张主推大卡 + All tracks 网格；封面按曲目 seed 生成渐变占位图。点击卡片即通过全局播放器单例播放，与顶栏抽屉、首页 Now Playing 卡片三方联动。

第十阶段：Home Photos 联动

Home 页 Photos 栏从占位文案改为真实数据：GET /api/photos?limit=4 取最近上传的 4 张照片渲染缩略图，点击跳转到对应相册，与 Photos 页实时联动。

踩过的坑

  • 加载动画遗留 Zppo：品牌文案改了页面，却没改站点配置里的加载动画文本。
  • 浅色主题下年月筛选的日历图标「消失」：原生控件颜色只受 color-scheme 控制，加 filter 无效，改成跟随主题切换 color-scheme 才修复。
  • Blog 详情页白天模式下黑底白字：从参考站复制正文时带入了硬编码深色背景内联样式，展示模式统一清除内联背景色解决。
  • 端口 8080 被占用：后端启动失败，先杀监听进程再重启。
  • 后端重启后旧登录 Token 全部失效：Token 存内存，重启即清，需重新登录。
  • 中文写入数据库乱码：PowerShell / MySQL CLI 编码不稳，改用 Python + pymysql 写入。

现状与下一步

目前 Home / Blog / Notes / About / Photos / Music 六个页面已全部接入编辑模式与真实接口。下一步计划：接入真实音频源替换模拟播放、给 Blog 补评论功能、以及部署上线。
